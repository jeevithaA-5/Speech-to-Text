# Speech-to-Text
 A responsive, modern web-based Speech-to-Text Converter built using HTML, CSS and JavaScript. It allows users to convert spoken words into written text in real time using speech recognition technology. The tool supports multiple languages, live transcription, voice input controls and text export options — making speech-to-text conversion simple and efficient.
🚀 Features
- 🎙️ Voice Recognition: Convert spoken words into text in real time.
- ▶️ Start/Stop Recording: Easily control voice recording.
- 📝 Live Transcription: Display recognized speech instantly in the text area.
- ✏️ Text Editing: Edit the converted text manually.
- 📥 Download Options:
  - Download converted text as TXT
  - Download converted text as PDF
- 📋 Copy to Clipboard: Copy converted text with a single click.
- 🔄 Clear Text: Remove the converted content instantly.
- 📊 Word and Character Count: Track the number of words and characters.
- 🔊 Text-to-Speech: Listen to the converted text using speech synthesis.
- 🎨 Dark/Light Mode: Switch between dark and light themes.
- ⏱️ Recording Status: Display microphone and recording status.
- 🖼️ Responsive UI: Clean, minimal interface suitable for desktop and mobile devices.
- 🧠 Speech Recognition API: Uses the browser's Web Speech API to recognize and convert speech into text.
